## ウェブとウェブアセンブリ

### サンプルプログラム : hello

#### ビルド

```sh
cd hello
make
```

#### 実行(ウェブサーバ起動)

```sh
cd hello
make serve
```

[localhost:8000](http://localhost:8000)

### サンプルプログラム : fetch

```sh
cd fetch
make
```

#### 実行(ウェブサーバ起動)

```sh
cd fetch
make serve
```

[localhost:8000](http://localhost:8000)
